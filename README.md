# Monopoly prototype

Откройте эту папку через Unity Hub с Unity 2022.3 LTS или новее и запустите сцену `Assets/Scenes/Main.unity`.

## Как играть

1. Нажмите `БРОСИТЬ КУБИКИ`.
2. Если участок свободен, нажмите `КУПИТЬ`.
3. Для передачи хода нажмите `Space`.
4. Побеждает игрок, который не обанкротился.

Прототип использует только Unity UI и не требует внешних ассетов. Для Android/iOS выберите нужную платформу в Build Settings после установки соответствующего модуля Unity.
