# Monopoly prototype

Откройте эту папку через Unity Hub с Unity 2022.3 LTS или новее и запустите сцену `Assets/Scenes/Main.unity`.

Игра рассчитана на телефон в **горизонтальной ориентации**: доска лежит в 3D по центру экрана,
меню партии встроено в середину доски. В Game View выберите соотношение 16:9 Landscape.

## Как играть

1. Нажмите `БРОСИТЬ КУБИКИ`.
2. Если участок свободен, нажмите `КУПИТЬ`.
3. Собрав группу целиком, стройте дома кнопкой `ДОМ` / `ОТЕЛЬ`.
4. Для передачи хода нажмите `ПЕРЕДАТЬ ХОД` или `Space`.
5. Побеждает игрок, который не обанкротился.

## Структура кода

Сцена содержит только пустой объект с `MonopolyGame` и камеру — вся сцена собирается кодом.

```
Assets/Scripts/
├── MonopolyGame.cs          точка входа: ход партии, связывает правила, доску и интерфейс
├── Core/                    правила и состояние, без единой ссылки на отрисовку
│   ├── GameRules.cs         числовые константы партии
│   ├── BoardData.cs         описание клеток: названия, цены, аренда, налоги, группы
│   ├── ChanceDeck.cs        колода карточек «ШАНС»
│   ├── GameState.cs         деньги, владельцы, дома, позиции + расчёты аренды и стройки
│   ├── GameLog.cs           журнал ходов
│   └── Palette.cs           общая палитра цветов
├── Board/                   3D-доска и сцена вокруг неё
│   ├── BoardLayout.cs       раскладка клеток: углы-квадраты и прямоугольники вплотную
│   ├── BoardView.cs         плоская доска, клетки, фишки и анимация перемещения
│   ├── BoardCamera.cs       вписывает доску в кадр и держит её по центру экрана
│   ├── Primitives.cs        меши без коллайдеров (модуль Physics в проекте не подключён)
│   └── SceneEnvironment.cs  сетчатый пол, свет и фон
└── UI/                      экранный интерфейс
    ├── UiFactory.cs         примитивы uGUI: панели, надписи, кнопки
    └── GameHud.cs           меню партии, встроенное в середину доски
```

Доска лежит горизонтально в плоскости XZ: клетки нарисованы на world-space канвасе, повёрнутом
на 90° вокруг X, а фишки — объёмные объекты, которые прыгают по клеткам. `BoardCamera` подбирает
дистанцию под текущее разрешение и держит доску по центру экрана.

Раскладка как на настоящей доске: 40 клеток — четыре угла-квадрата (СТАРТ, ТЮРЬМА, КАЗИНО,
СТОЯНКА) и по девять прямоугольных клеток между ними вплотную друг к другу, СТАРТ в левом верхнем
углу, движение по часовой стрелке. На каждой стороне свой вокзал, улиц 22: крайние группы по две,
остальные по три. Подписи клеток
развёрнуты наружу доски; чтобы все надписи стали вертикальными, достаточно вернуть 0 из
`BoardLayout.ContentAngle`.

Прототип использует только встроенный рендер и Unity UI, внешних ассетов не требует.
Для Android/iOS выберите нужную платформу в Build Settings; ориентация уже ограничена landscape.
